# Adam Heisey

Data scientist and economist focused on healthcare quality, patient safety, and applied statistics. Based in Seattle.

I build statistical monitoring and NLP tools that help clinical teams catch problems earlier: observed-to-expected anomaly detection, SPC control charts, and text classification on clinical notes. Before healthcare, I worked as an economist at the U.S. Energy Information Administration, with prior roles at SSA and FERC. Earlier, I did community economic development and program evaluation with the Peace Corps (Benin, Mali) and Mennonite Central Committee (Haiti).

**Tools:** Python · R · SQL · Databricks / Spark · NLTK · spaCy · Power BI · Tableau · Git

### Selected projects
- **[oe.anomaly](https://github.com/adamheisey22/oe.anomaly)**: O/E ratio significance testing and control limits (Vandenbroucke method), in R and Python
- **[si_ideation_work](https://github.com/adamheisey22/si_ideation_work)**: rule-based NLP for detecting suicidal ideation in clinical notes (NegEx, pyConText, C-SSRS)
- **[sentiment_analysis_lexicon](https://github.com/adamheisey22/sentiment_analysis_lexicon)**: VADER sentiment scoring with a custom domain lexicon
